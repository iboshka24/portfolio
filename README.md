# iboshka24 — сайт-портфолио

Одна страница: whoami, проекты, стек, чем занят сейчас. Тот же визуальный язык, что и в
профиле на GitHub — графит, оранжевый, лайм, — поэтому сайт и профиль читаются как одно.

## Что внутри

- `index.html` — вся страница, без сборки и фреймворков
- `styles.css` — мобильный вёрстка вперёд, `prefers-reduced-motion` уважается
- `app.js` — печатающаяся строка в терминале, появление блоков при прокрутке

## Локально

```bash
python3 -m http.server 8081   # http://127.0.0.1:8081
```

## На Vercel

Статический сайт, сборка не нужна: **Framework Preset = Other**, Root Directory = корень,
Build Command пустой, Output Directory пустой. Либо из терминала: `vercel --prod`.

Дальше в настройках домена можно привязать свой адрес — тогда ссылка в профиле станет
`iboshka24.tech` или любым другим.
